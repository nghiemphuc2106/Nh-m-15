📅 10/10/2024 | 👤 Tester | 📁 Công nghệ

Responsive web design đảm bảo website hiển thị tốt trên mọi thiết bị.

Breakpoints phổ biến

Thiết bịKích thước
Mobile≤ 768px
Tablet769px - 1024px
Desktop≥ 1025px

Mẹo thiết kế

  • Sử dụng flexbox và grid
  • Hình ảnh responsive (max-width: 100%)
  • Font size relative (rem, em)
  • Test trên nhiều thiết bị
